# Портфолио — Герман Сенин

Сайт на Astro (статическая генерация) в швейцарском стиле: чёрно-белый, строгая сетка,
крупная типографика. Список работ редактируется через админ-панель на `/admin` —
Decap CMS, без сервера и базы данных.

## Структура

```
src/content/work/*.md   — карточки проектов (название, категория, год, ссылка на видео, обложка)
src/pages/index.astro   — главная: заголовок + список работ
src/pages/work/[slug]   — страница отдельного проекта с плеером
public/admin            — админ-панель (Decap CMS)
public/covers           — обложки, которые загружаются через админку
```

## Запуск локально

```bash
npm install
npm run dev
```

Откройте http://localhost:4321 — сайт, и http://localhost:4321/admin — админка
(в `public/admin/config.yml` включён `local_backend: true`, поэтому логин не нужен,
пока вы работаете локально).

## Деплой (бесплатно): GitHub + Netlify

1. Создайте пустой репозиторий на GitHub и запушьте туда этот проект.
2. Зайдите на netlify.com → **Add new site → Import an existing project** → выберите репозиторий.
   Build command: `npm run build`, Publish directory: `dist`.
3. В настройках сайта включите **Identity** (Site configuration → Identity → Enable).
4. Там же включите **Git Gateway** (Identity → Services → Git Gateway).
5. В `public/admin/config.yml` удалите или закомментируйте строку `local_backend: true` —
   она нужна только для локальной разработки.
6. Пригласите себя как пользователя в Identity (Invite user, на свою почту), примете
   приглашение — после этого сможете логиниться на `https://ваш-сайт.netlify.app/admin`.

После этого админка полностью рабочая: заходите на `/admin`, добавляете, редактируете
или удаляете проекты, изменения сами коммитятся в GitHub и пересобирают сайт.

## Видео: где хранить бесплатно

Git и Netlify плохо подходят для больших видеофайлов, поэтому в CMS поле «Ссылка на
видео» — это просто текстовое поле для URL, а не загрузка файла. Видео нужно
захостить отдельно и вставить прямую ссылку на файл (.mp4). Варианты:

- **Cloudflare R2** — 10 ГБ хранилища бесплатно и без платы за исходящий трафик
  (самый выгодный вариант для видео). Создаёте bucket, включаете публичный доступ,
  загружаете файлы через веб-интерфейс.
- **Cloudinary** — бесплатный тариф с хостингом видео, включая автоматическое сжатие
  и генерацию превью. Проще в настройке, чем R2.
- **Bunny Stream** — не полностью бесплатно, но очень дёшево и с удобным плеером,
  если объём работ вырастет.

Обложки (постеры) грузятся прямо через админку в `public/covers` — тут ограничений
нет, это просто картинки.

## Что менять под себя

- Контакты и соцсети — `src/pages/contact.astro`.
- Текст на главной и странице «Обо мне» — `src/pages/index.astro`, `src/pages/about.astro`.
- Категории проектов в фильтре CMS — `public/admin/config.yml`, поле `category`.
- Цвета/шрифт — переменные в `src/styles/global.css`.
